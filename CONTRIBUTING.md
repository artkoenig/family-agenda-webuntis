# Contributing

This plugin is licensed under the GNU Affero General Public License v3 (`LICENSE`). Contributions are licensed under the same licence; there is no CLA.

Every commit carries a `Signed-off-by` line under the [Developer Certificate of Origin 1.1](https://developercertificate.org/), by which you certify that you have the right to submit it under this licence:

```
Signed-off-by: Your Name <you@example.org>
```

`git commit -s` adds it. CI refuses a pull request with a commit whose author did not sign it off.

Run `pnpm check` before opening a pull request.
